# Транслятор конфигурационного языка в YAML
## Описание 
Инструмент командной строки для преобразования текста из учебного конфигурационного языка в YAML формат. Реализован на Python с использованием парсер-генератора Lark для формального синтаксического анализа. Программа принимает входные данные через стандартный ввод и сохраняет результат в указанный файл.

# Задание
(Вариант 13)
Разработать инструмент командной строки для учебного конфигурационного языка, синтаксис которого приведен далее. Этот инструмент преобразует текст из входного формата в выходной. Синтаксические ошибки выявляются с выдачей сообщений.

# Синтаксис конфигурационного языка
#### Числа:
- `0[xX][0-9a-fA-F]+` - шестнадцатеричные числа
- `[0-9]+ ` - десятичные числа

#### Массивы:
- `[ значение; значение; значение; ... ] ` - разделителем является точка с запятой

#### Имена переменных и ключей:
- `[_a-z]+`

#### Объявление константы:
- `var имя := значение`

#### Вычисление константы:
- `${имя}`

## Функциональность
### Основные возможности
- Синтаксический анализ с использованием парсер-генератора Lark
- Преобразование в YAML с сохранением структуры данных
- Поддержка переменных с областью видимости
- Вложенные массивы произвольной глубины
- Обработка ошибок с понятными сообщениями

### Поддерживаемые конструкции
- Объявление переменных: `var port := 8080`
- Присваивание значений: `key := value` или `key: value`
- Шестнадцатеричные числа: `0xFF`, `0x1A`
- Десятичные числа: `123`, `45`
- Строки: `"text"`, `"path/to/file"`
- Массивы: `[1; 2; 3]`, `["a"; "b"]`
- Ссылки на переменные: `${variable_name}`
- Вложенные массивы: `[[1; 2]; [3; 4]]`

### Обработка ошибок
- Неопределенные переменные
- Синтаксические ошибки
- Отсутствие значений для параметров

## Примеры работы
### Пример 1: Конфигурация веб-сервера
Вводимый пользователем текст на конфигурационном языке:
```
var host := "localhost"
var port := 8080
var timeout := 30
var ssl_ports := [443; 8443]
server := [${host}; ${port}]
max_connections: 1000
allowed_ports := ${ssl_ports}
routes := ["/api"; "/static"; "/admin"]
backends := [["api1"; 8001]; ["api2"; 8002]]
log_level: "debug"
```

## Запуск
### Перед запуском требуется установка зависимостей
``` 
pip install lark
```

### Минимальный запуск
```
python config_parser.py --output_file
```
Итоговый yaml текст будет сохранен в файл output.yaml в директории проекта 

### Параметризированный запуск

```
python config_parser.py --output <имя файла>
```
Итоговый yaml текст будет сохранен в файл с заданным именем в заданной директории
